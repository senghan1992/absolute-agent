모델 연결 — 카드를 펼쳐 연결

            

              
              API 키는 이 PC에만 보관되고, 실행할 때 자동으로 입력됩니다.
            

            
custom(임의 OpenAI 호환 엔드포인트)은 맨 위 카드. 순서: 카드 펼치기 → 키·Base URL·모델 입력 → 연결 테스트 → 연결 저장

AI 모델 연결이 필요해요

        
진단은 AI가 분석합니다.
시작하려면 먼저 사용할 AI 모델을 연결해야 합니다.

        
설정(⚙) → 모델 연결에서 사용할 카드를 펼쳐 API 키를 입력하고 [연결 저장]을 누르세요.
연결되면 위 선택 목록에 나타나 바로 사용할 수 있습니다.
